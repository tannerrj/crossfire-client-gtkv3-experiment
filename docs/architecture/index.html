What is this?

The Crossfire Client is the graphical frontend for the Crossfire cooperative multiplayer RPG server. It connects over TCP using a custom binary protocol, receives map tile data, inventory, stats, and text messages, and renders them using the GTK3 widget toolkit and Cairo 2D graphics. This branch ports the existing GTK2 client to GTK3 while preserving the shared common/ protocol and data layer unchanged.

Shows the major data and control paths through the client at runtime. The server communicates via TCP; all other flows are in-process function calls or IPC pipes.

External libraries resolved at configure time via pkg-config. Required dependencies must be present. Optional features can be disabled with a cmake flag. Build-only tools are not linked into the binary.

Non-obvious architectural choices made during the GTK2→GTK3 port. These record the why so future maintainers do not have to rediscover the same constraints.
